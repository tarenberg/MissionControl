# ArtTracker Application Overview

ArtTracker is a web-based application designed to help users manage and track their artworks, shows, deadlines, and associated costs. It provides a dashboard interface for a quick overview and detailed sections for managing each aspect.

## Key Features:
*   **Artwork Management:** Keep track of individual artworks, including details like title, artist, images, and status.
*   **Show Management:** Organize and monitor art shows, exhibitions, and events where artworks are displayed.
*   **Deadline Tracking:** Manage important deadlines related to artworks, shows, or other tasks.
*   **Cost Management:** Record and categorize costs associated with artworks or shows.
*   **Dashboard Overview:** A central dashboard provides a summary of key information.

## Technology Stack:
*   **Frontend:** React with Vite for a fast and interactive user interface.
*   **Backend:** PHP API for handling data requests and business logic.
*   **Database:** MySQL for data storage.
*   **Web Server:** XAMPP (Apache) is used to serve the application and PHP backend.
