**Lessons Learned (Reinforced & Documented in `tasks/lessons.md`):**

*   **Critical Next.js Client/Server Component Boundaries:** Strict adherence is paramount. Node.js-specific modules (`os`, `fs`, `child_process`) **must not** be directly imported or used in client components (`"use client";`). All server-side logic requiring these must be offloaded to API routes or Server Actions, and client components must `fetch` data from these endpoints.
*   **`"use client";` Directive:** Essential for any React component using client-side hooks (`useState`, `useEffect`) or browser-specific APIs in Next.js 13+.
*   **Duplicate Declarations:** Always scan for duplicate function/variable declarations after code modifications.
*   **JSON Parsing Robustness:** Be aware of hidden characters (like BOM) that can cause `SyntaxError` in JSON files; re-writing the file with `JSON.stringify` can resolve this.
