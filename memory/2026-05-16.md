## Lessons Learned
- Automated "Error Monitors" can quickly bloat task files if not throttled, leading to model failures.
- When port conflicts occur in Windows, `netstat -ano | findstr :[port]` followed by `taskkill /F /PID [pid]` is the most reliable recovery path.
- User feedback on "Voice Activity Trigger" (VAT) revealed that automated silence detection can be "awkward"; manual "Send" with automated start/restart provides a better balance of control and friction-free input.
- **State Closure Trap**: When using `await` in a `useCallback`, any state variables used after the `await` will refer to the values at the time the function was *called*, not the updated state after the `await`. Watchers (`useEffect`) are safer for cross-state dependencies.
- **TDZ (Temporal Dead Zone)**: Be careful when passing callbacks into a hook that also provides the state used by those callbacks. If the callback depends on the hook's return value in its dependency array, it creates a initialization order error.
- **UX Flow**: Explicit mode switching (voice vs. typing) triggered by user focus/click is often more intuitive than "background" awareness timers.
- **Micro-interactions**: Auto-send on hover is a powerful ultra-low-friction pattern for experienced users, though it requires safeguards (like checking if the message is empty) to prevent accidental noise.
