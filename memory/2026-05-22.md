## Key Learnings & Decisions
- **Secure Context Options**: While HTTPS satisfies `getUserMedia` checks natively, self-signed SSL certificates can cause frustrating "Page not loading" errors or strict device blocks on some mobile browsers. Standard HTTP is much more reachable, and microphone access can be cleanly unlocked on desktop/laptop Chrome/Edge browsers using the `unsafely-treat-insecure-origin-as-secure` flag.
- **Microphone Echo Protection**: Always disable active VAD listeners when the AI assistant is thinking or speaking to prevent the synthesizer's voice output from being picked up and triggering infinite loop conversations.
