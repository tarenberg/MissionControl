## Key Learnings & Decisions
- **Secure Context Requirement**: Any modern voice feature (Web Speech API, getUserMedia, Gemini Live WebRTC) requires a secure context (HTTPS/localhost). Next.js's `--experimental-https` is the absolute cleanest local-first way to satisfy this requirement for Tailscale-connected devices without relying on external certificates.
- **Microphone Echo Protection**: Always disable active VAD listeners when the AI assistant is thinking or speaking to prevent the synthesizer's voice output from being picked up and triggering infinite loop conversations.
